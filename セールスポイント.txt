【作品名】TOON SLASHER (トゥーン スラッシャー)
【作品説明書・セールスポイント】
================================================================================

■ 1. 作品概要・ゲームの目的
--------------------------------------------------------------------------------
「敵を掴み、振り回し、投げ飛ばす！」
トゥーン調の世界観で展開する、爽快感とハイスピード感を極限まで追求した
3Dアクションゲームです。

【ゲームの流れ】
1. 【通常ステージ】
   - アリーナ内に展開されたタクティカルな敵陣形（前衛・属性中衛・後衛シューター）
     を相手に、掴み・スピン・投擲・パリィを駆使して戦います。
   - すべての敵を全滅させると、ボスステージへのカットシーンが発動します。
2. 【ボスステージ】
   - 巨大ボス「WARNING // BOSS」との決戦。
   - ボスはHP残量に応じて第1〜第3フェーズへと行動が激化
     （突進タックル、大ジャンプ衝撃波、落雷、磁力旋回弾）。
   - ボスを撃破することでゲームクリアとなります。
3. 【タイムアタック ＆ コンボシステム】
   - クリアタイムとスコアを競うタイムアタック機能を搭載。
   - 敵撃破でタイム -1.0秒、パリィ成功でタイム -2.0秒短縮！
   - 3コンボ以上でスコア倍率アップ＆金文字ポップアップ演出。


■ 2. 操作方法（キーボード ＆ マウス対応）
--------------------------------------------------------------------------------
【移動】            : [W][A][S][D]
【カメラ回転】      : マウス移動 （または [Q] / [E] キー）
【ジャンプ】        : [スペースキー] （空中でもう一度押すと「2段ジャンプ」）
【ダッシュ】        : [Shiftキー]
【掴む / 投げる】   : [マウス左クリック]
  - 敵の近くでクリック  : 敵を掴む
  - 掴み中に長押し      : 高速スピン（遠心力による周囲の敵なぎ払い）
  - クリックを離す      : 狙った方向へ敵を豪快に投擲（壁や敵へ激突）
【ガード / パリィ】 : [マウス右クリック]
  - 長押し              : ガード（防御姿勢）
  - 弾の着弾直前に押す  : 「ジャストガード（パリィ）」発動！
                          弾を完全反射し、敵をサンドバッグ化
【ジャスト回避】    : 敵弾・攻撃の直前に [Shiftキー] でダッシュ
  - 成立すると世界がスローモーションに突入
  - ロックオン枠が表示された敵に向かって [左クリック] で「電撃ワープスラッシュ」一閃！
【決定 / UI操作】   : [Enterキー] または [マウス左クリック]
【ポーズ / デバッグ】: [F1キー] （ImGuiデバッグメニュー開閉）


■ 3. 制作内容一覧
--------------------------------------------------------------------------------
◆ プレイヤーアクション
  - もちもちとしたスプリング変形を伴う歩行・バンク傾き・2段ジャンプ
  - 敵の掴み、遠心力スピン、投擲の物理演算システム
  - パリィ反射カウンター ＆ ジャスト回避からの電撃ワープスラッシュ一閃

◆ エネミー ＆ ボスシステム
  - 通常モブ敵、遠距離弾丸を放つシューター敵（AttackingEnemy）
  - 敵の属性を動的に拡張する Affix システム
    ・爆発敵（赤）: 投げると周囲12mを巻き込む大爆発
    ・電撃敵（水色）: 投げると最大5体へ連鎖するチェインライトニング
    ・サンドバッグ（緑）: 高耐久で武器として振り回せる練習台
  - 3段階の形態変化（フェーズ）を持つAI搭載の巨大ボス

◆ アイテムシステム
  - VACUUM（中央最奥）: 敵全体を渦潮のように吸い寄せるブラックホール
  - GIGANT（左翼）: 掴んだ敵を巨大化させ、広範囲を一気になぎ払う
  - LIGHTNING（右翼）: プレイヤー自身が電撃を纏い高速スラッシュ

◆ グラフィックス ＆ シェーダーパイプライン（DirectX 11）
  - 自作HLSLによるトゥーンシェーディング（階調セルルック）
  - 頂点法線押し出しによる動的キャラクターアウトライン（輪郭線）描画
  - ポストエフェクト（スローモーション時の彩度反転、ラジアルブラー、色収差、画面フラッシュ）
  - 頂点変位による動的な波打つフィールド ＆ 自転する巨大スカイドーム

◆ サウンドシステム（XAudio2 ＆ Media Foundation）
  - BGM（タイトル・通常戦・ボス戦・勝利・敗北）のスムーズな再生・切り替え
  - パリィ（金属音）、ジャスト回避（ピキーン音）、スラッシュ（斬撃音）、打撃音などのSE統合

◆ シーン ＆ UI ＆ デバッグ
  - タイトル → チュートリアル → 通常ステージ → ボスステージ → クリア / ゲームオーバー遷移
  - ヘキサゴン風プレイヤー/ボスHPゲージ、コンボポップアップ、フェードシステム
  - コリジョンワイヤーフレーム表示・無敵化・パラメータ調整が可能なImGui環境


■ 4. セールスポイント
--------------------------------------------------------------------------------
1. 【圧倒的な手応えと爽快感を生むヒット演出（Juice）】
   - 攻撃が当たった瞬間の「ヒットストップ（時間停止）」「カメラシェイク」「放射状ブラー」
     「色収差」「画面フラッシュ」「モデル潰れ（Squash & Stretch）」をミリ秒単位で徹底調律。
   - 敵を掴んで壁に叩きつけた時（壁ドン）や、パリィで弾き返した時の手応えは
     商用アクションゲームに匹敵する爽快感を追求しました。

2. 【直感的な操作性とハイリスク＆ハイリターンなバトル設計】
   - 敵の弾をあえてギリギリで引きつけて避ける「ジャスト回避」からの電撃一閃、
     ジャストガードによる「パリィ反射」など、プレイヤーの腕前がダイレクトに
     反映されるテクニカルな気持ちよさを実現しています。

3. 【空間分割グリッド（Spatial Grid）による高速コリジョン最適化】
   - 多数の敵、飛び交う弾、投擲された敵同士の当たり判定を $O(N^2)$ から大幅削減。
   - 派手な多重物理・爆発・電撃エフェクトが発生しても、処理落ちのない常時60FPSを維持します。

4. 【初心者にも優しいチュートリアルと充実のデバッグ機能】
   - タイトルからいつでも移動・攻撃・パリィを学べるチュートリアルを実装。
   - 審査やテストプレイをスムーズに行えるよう、F1キーによるImGuiデバッグメニューを搭載。
